# Icons

Line icons on a 24 × 24 grid: stroke 2.2 (2.4–2.6 for back, chevron, close and plus), round caps and joins, drawn in ink `#2A2414`. Recolour in code (on-ink in the tab bar, olive in the timer pill, white on olive). Names say what they mean: home, calendar, recipes, groceries, menu (tab bar); settings; person (Others in the calendar); car (who takes someone, in the day view and on the event page); cake (birthdays on Home's calendar card, spec 028); clock, repeat, pin and bell (the event page's when, repeat, place and reminder rows, spec 042); edit (the event page's ✎ in the top bar, spec 050; the recipe page's Edit, spec 051); book (a recipe's Source chip, spec 051); pot (the "Cooking now" card, spec 051); lock (a private event's Busy sheet, spec 043); people (Family) and sparkle (AI assistants) on the Menu's settings rows (spec 029, from OC-Menu); back, chevron-right, chevron-down and chevron-up (unit pickers), close, plus, search, filter, share, more, more-vertical (a grocery row's menu); timer, thermometer, screen-on (cooking); check, trash, camera, message, mail, swap (variant change), view-only, warning, play; undo (counter-clockwise arrow) and retry (circular arrow), the Toast's round buttons (spec 053, to draw in this set's stroke style).
