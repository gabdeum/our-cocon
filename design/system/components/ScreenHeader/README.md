# ScreenHeader

The top of a screen, in four forms: tab title, brand row, back link, and form bar.

## Specs

| Form | Spec |
| --- | --- |
| Tab title | `display-xl` 32/900 −0.6; optional sub-line 15/700 ink-muted ("7 items to buy · shared with family"); optional right action (small olive Button, presence pill) aligned to the bottom of the title |
| Brand row (Home) | mark 34 (honey, radius 11) + "Our Cocon" 18/900 −0.3, gap 8; avatar stack on the right; date 15/700 olive and greeting 32/900 below |
| Back link | 44 tall, chevron 22 + parent name 16/800 olive ("Settings"), then a `display-lg` 28/900 title and a lead 15/600 muted |
| Back link with summary | As Back link, 8 below it a `display-xl` 32/900 title with a summary 15/700 ink-muted on its baseline, right-aligned ("1 running · 3 total", OC-Timers) |
| Form bar | Cancel (16/800 muted link, 44) · title 17/900 centred · Save (Button olive sm); `Progress` with section names under it |

## Rules

Top padding is 50–54 below the status bar (safe area). Titles are nouns ("Groceries"); greetings use the member's first name.
