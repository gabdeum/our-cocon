# ResultTile

A converted amount: a big number over its unit (OC-Units' 2 × 2 grid).

## Specs

| Part | Spec |
| --- | --- |
| Tile | radius 20, padding 14 16; white, the main result `honey` |
| Number | 26/900, tabular |
| Unit | 15/700 ink ("cups", "fl oz (US)") |
| Layout | 2 columns, gap 10 |

## Rules

- Not tappable (unlike StatTile). Read as one phrase: "1¼ cups".
- Only the first tile is honey.
