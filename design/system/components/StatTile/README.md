# StatTile

A big-number shortcut on Home: "7 to buy", "32 family recipes".

## Specs

| Part | Spec |
| --- | --- |
| Tile | radius 24, padding 16 18, gap 16; `--honey` or `--sage` fill; whole tile is a link |
| Icon | 26 px, stroke 2, ink |
| Number | 28/900, line-height 1 |
| Label | 15/700 ink |
| Layout | two tiles side by side, gap 12 |

## Rules

Honey for things to act on (groceries), sage for collections (recipes). Numbers update live.
